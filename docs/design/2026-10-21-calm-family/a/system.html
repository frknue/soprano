Quiet

The same console with the lights dimmed. Mono chrome, orange still means “your keys go here”, and everything that glowed, striped, blinked or shouted is gone. Dark is primary; light is first-class. Mood: Zed (calm chrome, neutral selection) · Sublime Merge (dense git UI that reads quietly) · Ghostty (native chrome that disappears, dimmed unfocused splits).

    Mission Control → Quiet

    Item by item. Identity is kept (mono chrome, orange = active, status vocabulary, icon geometry); ornament is removed.

    Status system

    Solid = something is happening or needs you; ring = at rest. Only NEEDS INPUT and ERROR color their label. Aggregates take the most urgent member: error > waiting > running > starting > idle.

    Dark
    Light

    Focus · attention · selection

    Shape before hue: focus is a 1 px accent frame plus a raised header and a dim on the others; attention is a band on the header with a 2 px top line; selection is a neutral fill, with a 2 px accent tick only in the list that owns the keyboard.

    Components

    Every class from the components.css index, rendered in both modes from the same markup. Hover / pressed / disabled are static examples. A disabled .btn-primary (empty field, nothing to send) takes the standard disabled look — bgRaised, muted text — so a view never shows orange on an action that can't run.

    App-icon family

    Same squircle, same cream glyphs, exactly one flat orange “where you are” part, no glow. That part stays ≤ 20% of the glyph area, except Tab, whose orange part is the front window card itself (≈ 35%, the switcher's selected window). Glyph geometry kept from today; Cast loses its orange frame.

    Third-party themes under Quiet rules

    Real 16 values from Theme.swift; selection, hover, chips and dim derive from them. Attention falls back to the theme's ANSI 5 when accent and blue are within 30° of hue (Dracula, Solarized, Nord, Tokyo Night, Atom One Dark).
